# taldorei / items

Finished items art for the taldorei campaign site.

## Naming
Use lowercase, hyphenated, descriptive names:
`character-scene-version.ext` — e.g. `kaelen-portrait-v3.png`

## Workflow
1. Generate in the Gemini app (upload the character reference sheet first).
2. Download the winner here.
3. Reference it from the campaign HTML.
4. Push from your Mac (this Cowork environment can't reach GitHub).

## Format
PNG for portraits/items/banners, JPG acceptable for large scenes. Target min 1024px on the short side.
